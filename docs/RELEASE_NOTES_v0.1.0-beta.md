# Brothers in Arms: D-Day 한국어 패치 v0.1.0-beta

**대상:** PSP / ULUS10193 / USA v1.01  
**기준 빌드:** STEP129 COMPACT (STEP127 FIX1의 검증된 번역을 보존, STEP123–125/126 누적)  
**배포 형태:** 원본 ISO가 없는 xdelta3 패치

## 포함
- 캠페인 대사, 메뉴 및 일부 게임 내 안내 한국어화
- 일부 스커미시 텍스트 한국어화
- 영상 한글 자막, 11px 폰트 작업 누적
- 자막 화자가 바뀌는 세 장면의 줄바꿈 복원 (STEP125)
- `맥 중사` 계급 정리 및 레겟 `하지만 중사님...` 대사 수정 (STEP127 FIX1)
- 무기 모델명 원문 유지 원칙

## ISO 최적화
- ISO 3,311,890,432 → 1,413,019,648바이트 (활성 파일 1,147개 동일 데이터 SHA-256 검사)
- 최적화 ISO의 PPSSPP 정상 작동: 사용자 확인(전체 게임 완주 검증 아님)
- 이 릴리즈는 **STEP128 실험 ISO를 포함하지 않습니다.**

## 검증
- STEP125 화자 전환 자막 및 STEP127 FIX1의 레겟 대사: 실제 게임 화면 사용자 확인
- 배포 xdelta: 게시 전 원본에 **역적용 재생성** 후 결과 ISO 전체 SHA-256 일치 여부 확인
- 그 외 메뉴/영상/장면 전체 테스트는 완료되지 않음

## 남은 문제
- 저장하지 않고 계속할지 묻는 확인창 본문 영어 잔존. STEP128 실험은 사용자 화면에서 미해결로 확인돼 배포에서 제외
- 일부 UI 겹침/자세 아이콘, 게임 중 글리프 상태와 전수 실행 QA 미완료
- 게임 전체 한글화 완료판이 아닌 베타 패치

## 설치
GitHub Releases에서 `.xdelta`와 `manifest.json`을 내려받고 본인이 소유한 **정확한 USA v1.01 원본 ISO**에 적용합니다. 원본·결과 해시는 `manifest.json` 참고.
