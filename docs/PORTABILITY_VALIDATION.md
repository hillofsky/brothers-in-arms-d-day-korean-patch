# 개발 도구 검증 — 2026-10-16

## 실행 환경과 격리

Windows / Python 3.9.7에서 실행했다. 새 도구와 의존 소스/데이터를 별도 폴더로 복사하고, 저장소 루트가 아닌 작업 디렉터리에서 실행했다. 역사적 작업 폴더는 기준 ISO를 읽는 입력 경로로만 제공했다. 새 도구는 과거 개발 디렉터리의 스크립트나 이미지에 접근하지 않는다. Linux/macOS 실환경 검증은 NOT_RUN이다.

## 실제 기준과 결과

입력 STEP129의 SHA-256을 patch/manifest.json과 대조해 통과했다. D0_0130_.MDI의 SHA-256 `90fcd2550bf23f4b7763c67596cdcf4ffeacacb34bc7ffc1190eeb8ebea32677`은 기존 STEP127 FIX1 보고서 값과 일치했다.

- 전체 42개 MDI 스트림 해석 PASS.
- stream35 offset 0x1181c의 레겟 문구를 변경 없이 재압축/재삽입 PASS. 압축 방식 때문에 ISO 전체 해시는 기준과 달랐으며, 모든 압축 해제 스트림의 바이트는 일치했다.
- 같은 글자/바이트 길이를 유지하는 어순 변경을 합성 편집으로 사용했다. 번역 개선안이 아닌 변경 경로 검사다. 별도 폴더에서 실행한 후보 생성/MDI 전체 스트림 readback/대상 디렉터리·볼륨 크기 필드 외 기존 ISO 전체 바이트 비교 PASS.
- 기존 출력 경로 재사용, 틀린 기준 ISO, 틀린 old 문자열 assertion 거부 PASS.
- 기존 배포 manifest와 기준 ISO를 변경하지 않았다. 합성 ISO는 검사 후 삭제했다.
- 복구한 1,302행 원장/133행 자막의 역사적 status를 그대로 보존했다. STEP129와의 전수 적용 대조는 NOT_RUN이다.
